3. Hosting und Server-Logfiles

Diese Website wird bei GitHub Pages gehostet, einem Dienst der GitHub Inc., 88 Colin P Kelly Jr Street, San Francisco, CA 94107, USA. Beim Aufruf der Seite werden vom Server technisch notwendige Zugriffsdaten in sogenannten Logfiles erfasst. Dazu gehören in der Regel:

Die Übermittlung in die USA erfolgt auf Grundlage der Standardvertragsklauseln der EU-Kommission und der Zertifizierung von GitHub bzw. Microsoft unter dem EU-US Data Privacy Framework. Nähere Informationen zum Umgang mit Nutzerdaten finden Sie in der Datenschutzerklärung von GitHub: GitHub Privacy Statement.
